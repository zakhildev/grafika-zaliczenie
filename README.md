## Requirements

- Linux (Debian-based)
  - GLFW3 - `sudo apt install libglfw3 libglfw3-dev`
  - GLEW - `sudo apt install libglew-dev`
  - Assimp - `sudo apt install libassimp-dev`
  - Make - `sudo apt intall make`
  - g++ - `sudo apt install g++`

- MacOS
  - Assimp - `brew install assimp`
  - Xcode CLI Tools - `xcode-select --install`
  - Make - Provided Xcode CLI Tools
  - Clang++ - Provided Xcode CLI Tools
